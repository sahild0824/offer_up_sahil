# 2026 Fantasy Football Risk / Bust / Boom Signal Sources

Compiled 2026-09-04. **Method note:** the network egress proxy blocked `WebFetch` for every sports domain tried (FantasyPros, Draft Sharks, ESPN, Yahoo, CBS, SI, PFF, NFL.com, RotoWire, Bleacher Report, FTN, RotoBaller, WalterFootball, Fantasy Life, Reddit, etc.), so **all signals come from WebSearch result excerpts** (~56 searches) rather than full-page reads. Player names in a few excerpts were garbled by the search summarizer; where context made the identity clear (e.g., "Jaylen Harvey" -> RJ Harvey, "Allen Lazard/Ben Watson" -> Christian Watson, "Quentin/Stefon Flowers" -> Zay Flowers, "Parris Campbell (Downs)" -> Josh Downs, "Josh Warren" -> Tyler Warren, "Gabriel Wilson" -> Garrett Wilson) the canonical name is used and the mapping is noted in the JSON `notes`. One excerpt ("Stefon Diggs Moore ... top-5 WR season under Joe Brady in Buffalo", ESPN/Florio bold prediction) could not be resolved to a player and was **not** included.
